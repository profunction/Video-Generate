# Video Generate · AI Short Drama Studio

Windows 10/11 x64 Electron 桌面应用：

**故事创意 → 剧本与分镜 → 图片 → 阿里云 Wan 视频 → FFmpeg → 系统配音 / 字幕 → MP4**

**默认只需要一个阿里云百炼 API Key**：剧本由阿里云通义千问写，图片由阿里云万相画，视频由阿里云 Wan 生成，FFmpeg 已经打包在安装包里。不需要显卡，不用安装 Ollama、ComfyUI 或 FFmpeg，也不用开着任何本地服务；只有生成时需要打开应用。

第一次使用请看带截图的 [图解使用步骤：从 0 到完成](docs/QUICKSTART.md)。

想免费在本机写剧本或画图（例如想在 ComfyUI 里看和调整画图工作流），可以在设置里把“剧本由谁写”改成本机 Ollama、把“图片由谁画”改成本机 ComfyUI。也可以直接选择本地图片或填写 HTTPS 图片网址。

## 下载与安装

在仓库的 **Actions → Windows installer → 成功运行 → Artifacts** 下载 `Video-Generate-Windows-x64`，解压并运行 `.exe`。安装包未代码签名。应用可安装到已有版本之上；请先备份项目，默认保留旧配置与数据。安装包自带 FFmpeg / FFprobe（[gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 构建，GPL 许可证见安装目录 `resources/ffmpeg/LICENSE.txt`）。

开发：Node.js 22+，运行 `npm ci`、`npm start`。用源码运行时不带 FFmpeg，需要自己安装并加入 PATH，或在“高级设置”里填写完整路径。Windows 打包：`npm run dist:win`（把 `ffmpeg.exe`、`ffprobe.exe` 和许可证放进 `vendor/ffmpeg/` 才会打包进去，CI 会自动做这一步）。

## 首次配置（只需一次）

1. 登录[阿里云百炼控制台](https://bailian.console.aliyun.com/)，创建 API Key，记下它属于北京还是新加坡地域。
2. 在应用的“01 / 设置”里填写 API Key，选择与 Key 一致的地域，按控制台当前报价填写**视频每秒价格**和**每个项目预算**（币种相同）。价格默认 0，未填写前无法付费生成视频。
3. “剧本由谁写”和“图片由谁画”保持“阿里云”即可。按需开启“Windows 配音”。
4. 点“检测设置”。它会先保存屏幕上的设置，再检查 API Key 是否已保存、FFmpeg / FFprobe 能否启动；选了本机 Ollama / ComfyUI 时，还会检查它们的连接、模型和工作流。

**费用**：视频按秒计费，每次付费生成前都会弹出确认并检查预算。用阿里云画图时按张计费（`wan2.2-t2i-flash` 北京地域为 0.14 元/张，失败不收费，以[百炼价格页](https://help.aliyun.com/zh/model-studio/model-pricing)为准），付费确认框里会写明要画几张图；连续模式只需要画第 1 个镜头。用阿里云写剧本按 token 计费，每次用量很少。

**Windows 配音**：系统须安装相应语言的传统 SAPI 桌面语音（中文 Windows 一般自带）；Windows 设置中的部分自然语音不支持 System.Speech。语音名称可留空使用默认语音，或填写已安装的 SAPI 名称；名称填错时，错误提示会列出本机已安装的语音。每镜头旁白须短于这个镜头的长度（Wan 5 秒、Veo 8 秒），过长时程序会提示编辑，不会静默裁切。

### 可选：换一个服务生成视频

“视频由谁生成”默认是阿里云 Wan，也可以换成：

- **智谱 CogVideoX-Flash（免费）**：在[智谱开放平台](https://open.bigmodel.cn/)注册，创建 API Key，填进“智谱 API Key”。`cogvideox-flash` 目前免费（以智谱公告为准），所以不弹付费确认、不算预算，也不需要显卡。把“图片由谁画”选成“不画图”，就不需要 ComfyUI 或阿里云 Key，第 1 个镜头只按文字生成；有图片时（本地图片、ComfyUI / 阿里云画的图或上一个镜头的最后一帧）会以 Base64 发给智谱，连续镜头照样有效。每个镜头的长度以智谱返回的视频为准。画质一般不如阿里云 Wan，适合先免费测试。
- **Google Veo**：在 [Google AI Studio](https://aistudio.google.com/apikey) 创建 Gemini API Key，填进“Gemini API Key”。默认模型 `veo-3.1-generate-preview`，可在“高级设置”里修改。每个镜头 8 秒，按 Veo 的每秒价格填写“视频每秒价格”，预算和付费确认与 Wan 相同。镜头的第一张图（阿里云 / ComfyUI 画的图、本地图片或上一个镜头的最后一帧）会直接发给 Veo，所以连续镜头照样有效。用阿里云画图时仍需要阿里云 API Key。
- **自建 GPU 服务器**（例如自己部署的 Wan2.1 或 LTX-Video）：填写服务器地址（默认 `http://127.0.0.1:8081`）和可选的密钥。应用对每个镜头发送 `POST /generate`，请求体 `{"prompt": "…"}`，有密钥时带 `X-Inference-Key` 请求头，服务器直接返回 MP4。只按文字生成，不需要图片，也不计算费用（服务器费用请在 GPU 服务商处管理）。每个镜头的长度以服务器返回的视频为准。

已经提交给某个服务的镜头只能用同一个服务恢复；中途切换时会提示切换回去。字幕、配音和合并都按每个镜头自己的长度（Wan 5 秒、Veo 8 秒、智谱和自建服务器按实际长度）对齐。

### 可选：本机 Ollama 写剧本

安装 [Ollama for Windows](https://ollama.com/download/windows)，在终端运行 `ollama pull qwen2.5:7b`（需要 Ollama 0.5 或更新版本）。在设置里把“剧本由谁写”改成“本机 Ollama”，默认地址 `http://127.0.0.1:11434`。

### 可选：本机 ComfyUI 画图（可以看和调整工作流）

1. 安装 [ComfyUI](https://docs.comfy.org/installation/desktop/windows)，把 SD1.5 模型（例如 [`v1-5-pruned-emaonly-fp16.safetensors`](https://huggingface.co/Comfy-Org/stable-diffusion-v1-5-archive/blob/main/v1-5-pruned-emaonly-fp16.safetensors)）放进 ComfyUI 的 `models/checkpoints`，启动 ComfyUI。在设置里把“图片由谁画”改成“本机 ComfyUI”，填写 ComfyUI 启动后显示的地址（默认 `http://127.0.0.1:8188`）。应用**自带 SD1.5 画图工作流**（912×512，接近 16:9），会自动使用 ComfyUI 里装好的 SD1.5 模型，不需要导入任何文件。
2. **在 ComfyUI 里看和调整这个工作流**：点“在 ComfyUI 里看和调整工作流”，应用会把它放进 ComfyUI 的“工作流”（Workflows）列表并打开 ComfyUI。打开列表里的“Video Generate”，就能看到全部节点（带中文说明），可以改模型、图片大小、步数、CFG、采样器和正负提示词，改完按 Ctrl+S 保存，应用下次画图就用你保存的版本，不需要导出或导入。正向提示词里的 `{{PROMPT}}` 不能删，删了会在付费前提示。暂不支持子图（subgraph），缺少的插件节点会在付费前报出名字。
3. 想用自己的工作流（例如 SDXL / Flux）：在 ComfyUI 导出 **API 格式 JSON**，把正向提示词替换为 `{{PROMPT}}`，确保包含 `SaveImage` 节点，再点“导入自己的 ComfyUI 工作流（可选）”。只导入可信的工作流，模型和自定义节点须事先安装。工作流里的模型在 ComfyUI 中找不到时，会自动换成已安装的 SD1.5 模型。点“改用内置工作流”可以回到内置工作流，同时把 ComfyUI 里的“Video Generate”恢复成默认设置。使用顺序：导入的工作流 → ComfyUI 里保存的“Video Generate” → 内置工作流。[示例工作流](examples/comfy-sd15-api.json)与内置工作流相同。
4. 检测时，如果 Ollama 或 ComfyUI 的地址填错，但它们正在常用地址（11434 / 8188 / 8000）上运行，会直接提示正确地址。

## 一键生成

输入故事创意和镜头数量，点击“一键生成完整短剧”。应用自动写剧本、保存项目，然后为需要的镜头画图并上传，接着调用 Wan、下载视频、合并并导出字幕与可选配音。**每次提交新的付费 Wan 任务前必须在原生对话框明确批准**；取消则不会上传图片或提交新视频任务。用本机 Ollama 写剧本时不需要 Key；用阿里云写剧本需要先保存 Key。

也可以点击“生成剧本并编辑”，检查人物、提示词和旁白后保存项目，再“生成 / 恢复”。手动路径可使用图片网址或“选择本地图片”（PNG / JPEG），本地图片复制到项目内保存，长边超过 1920 像素时自动缩小；空图片配合生图提示词会使用 ComfyUI。CPU 上用 Ollama 写长剧本可能需要几分钟，最长等待 15 分钟。

## 镜头衔接：让人物和画面保持一致

生成剧本前，在“镜头衔接”里选择：

- **连续**（默认）：只有第 1 个镜头需要图片。后面每个镜头都从上一个镜头视频的最后一帧开始，所以人物、服装和场景不会变。Ollama 会按一镜到底来写剧本，不会突然换地点或跳到第二天。
- **独立**：每个镜头用自己的图片（本地图片、网址或 ComfyUI 生图），可以换场景，但不同图片里的人物可能不完全一样。

除第 1 个镜头外，每个镜头都有“接上一个镜头的最后一帧”勾选框，可以单独调整：例如在需要换场景的镜头取消勾选，给它一张新图，后面的镜头再接着它。镜头仍然逐个生成，每个镜头还是一个付费任务。连续接很多个镜头时画质可能慢慢变差，可以中途取消勾选、用一张新图重新开始。

“编辑分镜 / 旁白”支持修改已保存项目；已提交 Wan 的镜头锁定视觉提示词和图片，避免已有任务与编辑内容不一致，但仍可修改旁白并重新导出。未提交镜头修改生图提示词，或清空 ComfyUI 生成的本地图片后，会重新生图；自己选择的本地图片会保留。要改变镜头数量，请新建项目。

## 导出与恢复

- `final.mp4`：1280×720 / 24fps，无声合并版本。
- `drama.mp4`：有旁白文本时生成，包含可选的配音和可切换字幕轨；播放器中开启字幕即可显示。
- `subtitles.srt`：按每个镜头的长度排好时间的独立字幕文件；没有旁白的镜头不生成空字幕。
- `image-*.png`、`clip-*.mp4`：中间素材，保存在项目文件夹中。
- `frame-*.png`：连续镜头开头用的上一个镜头的最后一帧。

合并时每个片段都会裁剪或补帧到这个镜头的长度（Wan 5 秒、Veo 8 秒），旁白、字幕和画面不会随镜头数增加而错位。

中断后点击“生成 / 恢复”：ComfyUI 保存 prompt ID 后继续查结果；Wan 保存 task ID 后继续轮询，不重新提交。ComfyUI 重启后丢失任务时，应用会自动重新生图一次（本地生图不收费）。工作流完成但没有 SaveImage 输出时会立即报错，不再空等一小时。视频文件被误删时，只要 Wan 任务仍在 24 小时有效期内，恢复会用原任务重新下载，不会新建付费任务；下载内容不是有效视频时会删除并保留任务 ID，下次恢复重新下载。付费生成期间保持窗口开启（只写剧本时可以关闭）。应用只允许运行一个实例，避免两个窗口重复提交同一项目。图像提示词重复描述人物以改善一致性，但不能保证人物完全一致；参考图与角色 LoRA 等可在工作流中自行配置。

本地和 ComfyUI 图片经用户付费确认后自动上传到 [DashScope 临时文件空间](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)，不需要另配 OSS Key，有效期 48 小时，仅供个人低频使用；阿里云不建议用于生产高并发。应用提交前重新上传，避免复用过期 URL。生产部署请改用长期 OSS 存储。图片与提示词会发送给阿里云。HTTP 下载、API / 模型可用性受账号、网络和区域影响。

## 数据与费用保护

Windows Key 使用 Electron safeStorage / DPAPI 加密，保存在 Electron userData 目录。项目保存在其 `projects` 子目录，通过“打开项目文件夹”访问；卸载默认不删除。旧版项目无须迁移。

付费提交不自动重试；轮询对 429 / 5xx 退避重试。每次付费请求发出前写入预留费用和提交状态，任务成功响应后记录 ID。阿里云明确拒绝请求（HTTP 4xx，例如 Key、模型、图片或内容审核问题）时没有创建任务：应用显示阿里云返回的错误码和原因，并退回这次预留，修改后可直接重试。若请求结果不明（断网、超时、5xx），镜头标记为 `uncertain` 并在付费确认前停止，防止重复收费。只重新导出已生成的项目时，不需要单价和预算。

Wan 任务 `FAILED` / `CANCELED`，或超过 24 小时有效期后查询为 `UNKNOWN` 时，该镜头会解锁，可修改提示词或图片后重新生成；重新提交仍需付费确认。失败任务 ID 记录在 `failedTasks` 中，预留费用不退回（以阿里云账单为准，可按需提高预算）。

若请求结果不明，先到阿里云控制台核实，找到 ID 后关闭应用、备份 JSON，再给镜头设置 `taskId`、`region`、`model` 与 `uncertain: false`，然后恢复；不要未经核实创建替代项目。

预留费用保守累计：只有阿里云明确拒绝（未创建任务）时退回，任务失败不自动退回；预算由用户填写价格估算，不能代替云账号额度，也不能限制其他客户端消费。下载失败可以恢复。轮询超时后可再次恢复。

## 验证范围

`npm test` 覆盖预算、付费请求不重复提交、轮询、结构化剧本验证、工作流参数替换、字幕时间轴，以及模拟 Ollama → ComfyUI → 图片上传 → Wan 后实际用 FFmpeg 生成 MP4 和字幕轨的连通测试。付费流水线（`app/pipeline.js`）单独测试拒绝退回、结果不明锁定、失败解锁、重新下载和 ComfyUI 重启恢复。模拟服务不会产生云费用。

Windows CI 安装 FFmpeg，执行测试、Electron 系统加密 / 中文路径 / 界面隔离 smoke，并构建 NSIS 安装包。Windows Server CI 不等于 Windows 11 实机验证。尚未在真实 Ollama / ComfyUI 模型、Windows 11 和真实付费 Wan 上完成验收；请按 [验收清单](docs/WINDOWS-ACCEPTANCE.md) 验证。开发过程中未提交付费请求。

当前没有背景音乐混音、自动安装模型或角色训练功能。
