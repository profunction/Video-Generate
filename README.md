# Video Generate · AI Short Drama Studio

Windows 10/11 x64 Electron 桌面应用，现已接通：

**故事创意 → Ollama 剧本与分镜 → ComfyUI 图片 → 阿里云 Wan 视频 → 下载 → FFmpeg → 系统配音 / 字幕 → MP4**

ComfyUI 可选；也可以直接选择本地图片或填写 HTTPS 图片网址。云端 Wan 不需要 NVIDIA GPU。本地模型的速度和显存要求取决于所选模型。程序不要求 Docker 或自建云服务器。

## 下载与安装

在仓库的 **Actions → Windows installer → 成功运行 → Artifacts** 下载 `Video-Generate-Windows-x64`，解压并运行 `.exe`。安装包未代码签名。应用可安装到已有版本之上；请先备份项目，默认保留旧配置与数据。

开发：Node.js 22+，运行 `npm ci`、`npm start`。Windows 打包：`npm run dist:win`。

## 首次配置（只需一次）

1. 安装 [Ollama for Windows](https://ollama.com/download/windows)，在终端运行 `ollama pull qwen2.5:7b`。需要 Ollama 0.5 或更新版本（使用结构化 JSON 输出）。模型名称可改成你已有的模型。默认地址 `http://127.0.0.1:11434`。
2. 可选：安装 [ComfyUI](https://docs.comfy.org/installation/desktop/windows) 与适合电脑的生图模型，启动服务。默认连接地址 `http://127.0.0.1:8188`，以实际启动日志为准。硬件不适合本地生图时，跳过 ComfyUI，使用已有图片。
3. 用 ComfyUI 画图时，把 SD1.5 模型（例如 [`v1-5-pruned-emaonly-fp16.safetensors`](https://huggingface.co/Comfy-Org/stable-diffusion-v1-5-archive/blob/main/v1-5-pruned-emaonly-fp16.safetensors)）放进 ComfyUI 的 `models/checkpoints`，启动 ComfyUI 即可。应用**自带 SD1.5 画图工作流**（912×512，接近 16:9），会自动使用 ComfyUI 里装好的 SD1.5 模型，不需要导入任何文件。
   - 想用自己的工作流（例如 SDXL / Flux）：在 ComfyUI 导出 **API 格式 JSON**，把正向提示词替换为 `{{PROMPT}}`，确保包含 `SaveImage` 节点，再点“导入自己的 ComfyUI 工作流（可选）”。只导入可信的工作流，模型和自定义节点须事先安装。工作流里的模型在 ComfyUI 中找不到时，会自动换成已安装的 SD1.5 模型。点“改用内置工作流”可以回到内置工作流。[示例工作流](examples/comfy-sd15-api.json)与内置工作流相同。
4. 安装 [FFmpeg](https://www.gyan.dev/ffmpeg/builds/)，把 FFmpeg 和 FFprobe 加入 PATH，或在应用填写两个 `.exe` 的完整路径。
5. 在应用填写阿里云百炼 / DashScope API Key、相匹配的北京或新加坡区域及该区域可用的 Wan 模型。默认 `wan2.2-i2v-flash`，固定请求 5 秒、720P。按官方当前报价填写每秒价格和项目预算，币种相同。价格默认 0，未填写前无法付费生成。
6. 按需开启“Windows 配音”。系统须安装相应语言的传统 SAPI 桌面语音；Windows 设置中的部分自然语音不支持 System.Speech。语音名称可留空使用默认语音，或填写已安装的 SAPI 名称；名称填错时，错误提示会列出本机已安装的语音。每镜头旁白须短于 5 秒，过长时程序会提示编辑，不会静默裁切。
7. 点击“保存设置”，再点击“检测 Ollama / ComfyUI / FFmpeg”，它会检查服务连接、Ollama 模型是否已拉取、用的是内置还是导入的工作流以及会用哪个 ComfyUI 模型，还有 FFmpeg / FFprobe 能否启动。应用连接这些已安装的服务；**安装包不包含 Ollama、ComfyUI、模型、FFmpeg**，不会自动下载大型模型。

## 一键生成

输入故事创意和镜头数量，点击“一键生成完整短剧”。应用自动调用 Ollama、保存项目，然后连接 ComfyUI 逐镜头生图并上传，接着调用 Wan、下载视频、合并并导出字幕与可选配音。**每次提交新的付费 Wan 任务前必须在原生对话框明确批准**；取消则不会上传图片或提交新视频任务。Ollama 剧本生成属于本地操作，不需要 Wan Key。

也可以点击“生成剧本并编辑”，检查人物、提示词和旁白后保存项目，再“生成 / 恢复”。手动路径可使用图片网址或“选择本地图片”（PNG / JPEG），本地图片复制到项目内保存，长边超过 1920 像素时自动缩小；空图片配合生图提示词会使用 ComfyUI。CPU 上用 Ollama 写长剧本可能需要几分钟，最长等待 15 分钟。

## 镜头衔接：让人物和画面保持一致

生成剧本前，在“镜头衔接”里选择：

- **连续**（默认）：只有第 1 个镜头需要图片。后面每个镜头都从上一个镜头视频的最后一帧开始，所以人物、服装和场景不会变。Ollama 会按一镜到底来写剧本，不会突然换地点或跳到第二天。
- **独立**：每个镜头用自己的图片（本地图片、网址或 ComfyUI 生图），可以换场景，但不同图片里的人物可能不完全一样。

除第 1 个镜头外，每个镜头都有“接上一个镜头的最后一帧”勾选框，可以单独调整：例如在需要换场景的镜头取消勾选，给它一张新图，后面的镜头再接着它。镜头仍然逐个生成，每个镜头还是一个付费任务。连续接很多个镜头时画质可能慢慢变差，可以中途取消勾选、用一张新图重新开始。

“编辑分镜 / 旁白”支持修改已保存项目；已提交 Wan 的镜头锁定视觉提示词和图片，避免已有任务与编辑内容不一致，但仍可修改旁白并重新导出。未提交镜头修改生图提示词，或清空 ComfyUI 生成的本地图片后，会重新生图；自己选择的本地图片会保留。要改变镜头数量，请新建项目。

## 导出与恢复

- `final.mp4`：1280×720 / 24fps，无声合并版本。
- `drama.mp4`：有旁白文本时生成，包含可选的配音和可切换字幕轨；播放器中开启字幕即可显示。
- `subtitles.srt`：每镜头 5 秒的独立字幕文件；没有旁白的镜头不生成空字幕。
- `image-*.png`、`clip-*.mp4`：中间素材，保存在项目文件夹中。
- `frame-*.png`：连续镜头开头用的上一个镜头的最后一帧。

合并时每个片段都会裁剪或补帧到正好 5 秒，旁白、字幕和画面不会随镜头数增加而错位。

中断后点击“生成 / 恢复”：ComfyUI 保存 prompt ID 后继续查结果；Wan 保存 task ID 后继续轮询，不重新提交。ComfyUI 重启后丢失任务时，应用会自动重新生图一次（本地生图不收费）。工作流完成但没有 SaveImage 输出时会立即报错，不再空等一小时。视频文件被误删时，只要 Wan 任务仍在 24 小时有效期内，恢复会用原任务重新下载，不会新建付费任务；下载内容不是有效视频时会删除并保留任务 ID，下次恢复重新下载。付费生成期间保持窗口开启（只写剧本时可以关闭）。应用只允许运行一个实例，避免两个窗口重复提交同一项目。图像提示词重复描述人物以改善一致性，但不能保证人物完全一致；参考图与角色 LoRA 等可在工作流中自行配置。

本地和 ComfyUI 图片经用户付费确认后自动上传到 [DashScope 临时文件空间](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)，不需要另配 OSS Key，有效期 48 小时，仅供个人低频使用；阿里云不建议用于生产高并发。应用提交前重新上传，避免复用过期 URL。生产部署请改用长期 OSS 存储。图片与提示词会发送给阿里云。HTTP 下载、API / 模型可用性受账号、网络和区域影响。

## 数据与费用保护

Windows Key 使用 Electron safeStorage / DPAPI 加密，保存在 Electron userData 目录。项目保存在其 `projects` 子目录，通过“打开项目文件夹”访问；卸载默认不删除。旧版项目无须迁移。

付费提交不自动重试；轮询对 429 / 5xx 退避重试。每次付费请求发出前写入预留费用和提交状态，任务成功响应后记录 ID。阿里云明确拒绝请求（HTTP 4xx，例如 Key、模型、图片或内容审核问题）时没有创建任务：应用显示阿里云返回的错误码和原因，并退回这次预留，修改后可直接重试。若请求结果不明（断网、超时、5xx），镜头标记为 `uncertain` 并在付费确认前停止，防止重复收费。只重新导出已生成的项目时，不需要单价和预算。

Wan 任务 `FAILED` / `CANCELED`，或超过 24 小时有效期后查询为 `UNKNOWN` 时，该镜头会解锁，可修改提示词或图片后重新生成；重新提交仍需付费确认。失败任务 ID 记录在 `failedTasks` 中，预留费用不退回（以阿里云账单为准，可按需提高预算）。

若请求结果不明，先到阿里云控制台核实，找到 ID 后关闭应用、备份 JSON，再给镜头设置 `taskId`、`region`、`model` 与 `uncertain: false`，然后恢复；不要未经核实创建替代项目。

预留费用保守累计：只有阿里云明确拒绝（未创建任务）时退回，任务失败不自动退回；预算由用户填写价格估算，不能代替云账号额度，也不能限制其他客户端消费。下载失败可以恢复。轮询超时后可再次恢复。

## 验证范围

`npm test` 覆盖预算、付费请求不重复提交、轮询、结构化剧本验证、工作流参数替换、字幕时间轴，以及模拟 Ollama → ComfyUI → 图片上传 → Wan 后实际用 FFmpeg 生成 MP4 和字幕轨的连通测试。付费流水线（`app/pipeline.js`）单独测试拒绝退回、结果不明锁定、失败解锁、重新下载和 ComfyUI 重启恢复。模拟服务不会产生云费用。

Windows CI 安装 FFmpeg，执行测试、Electron 系统加密 / 中文路径 / 界面隔离 smoke，并构建 NSIS 安装包。Windows Server CI 不等于 Windows 11 实机验证。尚未在真实 Ollama / ComfyUI 模型、Windows 11 和真实付费 Wan 上完成验收；请按 [验收清单](docs/WINDOWS-ACCEPTANCE.md) 验证。开发过程中未提交付费请求。

当前没有背景音乐混音、自动安装模型或角色训练功能。
