WAN · VEO

01 / 设置

只需要一个阿里云百炼 API Key：剧本、图片和视频都可以在阿里云生成（视频也可以改用 Google Veo 或自己的 GPU 服务器），不需要显卡，也不用安装别的软件。Key 用 Windows 系统加密保存。

用 ComfyUI 画图时：安装并启动 ComfyUI，把 SD1.5 模型（例如 v1-5-pruned-emaonly-fp16.safetensors）放进 models/checkpoints。应用自带 SD1.5 工作流，会自动使用你装好的模型。点“在 ComfyUI 里看和调整工作流”，在 ComfyUI 左边的“工作流”列表里打开“Video Generate”，改完按 Ctrl+S 保存即可。

高级设置（模型、FFmpeg）

安装包已经自带 FFmpeg，路径保持 ffmpeg / ffprobe 即可；填了完整路径时用你填的那个。

02 / 故事与分镜

一键流程：写剧本 → 画图 → Wan 视频 → 配音 / 字幕 / MP4。默认全部用阿里云，只需要先保存 API Key；生成视频前会弹出付费确认。也可以自己写镜头、选本地图片。连续模式只需要第 1 个镜头的图片，后面的镜头从上一个镜头的最后一帧接着拍。字幕为 MP4 可选字幕轨，同时导出 SRT。每镜头旁白需控制在 5 秒以内。

03 / 生成与导出

一键依次提交分镜、下载片段并合并 MP4。提交付费请求前会弹出确认。恢复会使用已有任务 ID；支持字幕和可选的 Windows 系统配音。
