01 / 一键连接完整环境

不用分别下载工具或手动配置工作流。首次点击下方按钮，程序会下载并连接 Ollama、ComfyUI、默认模型和 FFmpeg。约 10 GB 下载，至少预留 25 GB 磁盘，建议 16 GB 内存；后续启动服务自动完成。

完成后只需保存阿里云 Key、区域和价格预算，然后到下方输入故事，点击“一键生成完整短剧”。已有环境仍可使用下方高级设置。

无需 NVIDIA 显卡。API Key 使用系统加密保存；Windows 使用 DPAPI。

首次配置本地 AI

先安装 Ollama，然后在终端运行 ollama pull qwen2.5:7b。安装 ComfyUI 与适合硬件的模型并启动服务；在 ComfyUI 中导出 API 格式的工作流 JSON，把正向提示词替换为 {{PROMPT}}，保留负向提示词，确保包含 SaveImage 节点，然后在此导入。无需 ComfyUI 时，直接选择本地图片或填写图片网址。也可使用顶部一键环境配置，自动完成下载、启动和工作流设置。

02 / 故事与分镜

一键流程：Ollama 剧本 → ComfyUI 分镜图片 → 上传阿里云 → Wan 视频 → 配音 / 字幕 / MP4。先完成一键环境配置或手动连接工具，再保存云端设置；付费调用仍需确认。也可手动填写或选择本地图片。字幕为 MP4 可选字幕轨，同时导出 SRT。每镜头旁白需控制在 5 秒以内。

03 / 生成与导出

一键依次提交分镜、下载片段并合并 MP4。提交付费请求前会弹出确认。恢复会使用已有任务 ID；支持字幕和可选的 Windows 系统配音。
