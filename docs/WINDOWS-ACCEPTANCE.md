# Windows 10/11 验收清单

目标为 Windows 10/11 x64。CI 使用 Windows Server 2022，不能据此声称已完成 Windows 11 实机测试。

## 自动化覆盖

- Node 测试：预算、付费请求不自动重试、轮询退避和失败处理。
- 付费流水线：阿里云明确拒绝时退回预留、结果不明时保持 `uncertain` 并阻止重复提交、失败或过期任务解锁镜头、误删视频按原任务重新下载、无效下载被丢弃、ComfyUI 重启后自动重新生图。
- 工具与本地 AI：FFmpeg / FFprobe / PowerShell 报错带原始原因，Ollama 与 ComfyUI 的错误详情，提示词中的 `$` 字符，无旁白镜头不生成空字幕，每个片段精确 5 秒。
- FFmpeg + FFprobe：在包含中文和空格的临时路径中，生成不同尺寸的视频并合并。
- Electron 桌面 smoke：真实系统加密往返、加密文件写入中文路径、界面加载、预加载桥接和 Node 隔离。
- NSIS：构建 Windows x64 安装程序，上传 Actions artifact。

## Windows 11 实机验收（尚未执行）

1. 在没有 NVIDIA GPU、Docker、Node.js 的电脑上安装 artifact 中的 exe；确认应用可以启动。
2. 设置 FFmpeg / FFprobe 的完整路径（包括中文和空格），保存设置后重启，确认设置和 Key 状态保留。
3. 保存多个分镜项目，关闭重开，确认项目列表保留。
4. 保持价格为 0，尝试生成，确认拒绝提交。
5. 配置有效价格、低于预估费用的预算，确认预算拦截。
6. 配置有效 Key、区域、模型和图片；在付费确认中取消，确认阿里云无新任务。
7. 仅在明确批准付费后测试生成、轮询、下载和最终 MP4；记录实际账单。
8. 查询任务时模拟网络中断，恢复网络后使用已有任务 ID 继续，确认不重复提交。
9. 备份项目目录后，卸载并重新安装，确认项目保留。

不要把真实 API Key、带私人凭据的 URL 或用户项目提交到 GitHub。

## 0.2 自动短剧流程（尚需真实服务验收）

1. 安装 Ollama 并拉取模型；点击连接检测，确认显示已安装模型；断开服务时应显示错误；模型名填错时应提示 `ollama pull`。
2. 配置可运行的 ComfyUI API 工作流，正向文本使用 {{PROMPT}}，导入；普通 UI JSON 应被拒绝。
3. 点击“生成剧本并编辑”，检查镜头数量、人物描述和旁白，并保存。
4. 用本地 PNG/JPG 图片创建另一项目；删除原始文件，确认项目内副本仍存在；超过 1920 像素的照片应被缩小。
5. 仅在明确批准费用后测试“一键生成完整短剧”，核对每镜头只有一个 Wan 任务。
6. 在 ComfyUI 已提交后中断应用并重启，检查恢复使用相同 prompt ID；Wan 同理。
7. 确认 MP4 的字幕轨可以开启，SRT 时间轴每镜头 5 秒；启用系统配音后验证语言和声音。
8. 旁白超过 5 秒时应提示修改；编辑旁白后再次导出，不得新增 Wan 视频任务。
9. 从 0.1 升级，打开旧项目并重新导出，确认旧素材与配置保留。
10. 在未安装 ComfyUI 的电脑上用本地图片或 HTTPS 图片仍能生成，说明 ComfyUI 保持可选。

## 0.2.1 加固（尚需真实服务验收）

1. 同时双击两次快捷方式，确认只出现一个窗口。
2. 在项目文件夹放入 `desktop.ini` 或把某个 `project.json` 改坏，确认项目列表仍可显示，坏项目只提供“打开项目文件夹”。
3. 使用错误的 Key 或模型提交，确认提示显示阿里云错误码，镜头没有被标记为 `uncertain`，预留费用已退回。
4. 删除某个已下载的 `clip-*.mp4` 后在 24 小时内恢复，确认没有新的 Wan 任务，视频重新下载。
5. 填写不存在的系统语音名称并开启配音，确认错误提示列出已安装的语音。

## 0.3 连续镜头（尚需真实服务验收）

1. 选择“连续”，只给第 1 个镜头图片，生成后确认第 2 个镜头的开头与第 1 个镜头的结尾是同一画面，人物不变。
2. 在第 3 个镜头取消勾选并换一张图，确认它使用新图，第 4 个镜头接着第 3 个镜头。
3. 在连续镜头生成中途关闭网络再恢复，确认已提交的镜头不会重新提交，未提交的镜头仍从上一个镜头的最后一帧开始。

## 0.4 内置 ComfyUI 工作流（尚需真实服务验收）

1. 不导入任何工作流，只把 SD1.5 模型放进 ComfyUI 的 `models/checkpoints`，点检测，确认显示 `built-in SD1.5 · model <模型文件名>`。
2. 不选任何本地图片，用“独立”模式生成，确认每个镜头的图片由 ComfyUI 画出，并且不会提示导入工作流。
3. ComfyUI 只装了 SDXL 模型时，确认在付费确认之前就提示下载 SD1.5 模型。
4. 导入自己的工作流后点“改用内置工作流”，确认检测结果回到 `built-in`。

## 0.5 在 ComfyUI 里调整工作流（尚需真实服务验收）

1. 点“在 ComfyUI 里调整工作流”，确认浏览器打开 ComfyUI，左边“工作流”列表里出现“Video Generate”，打开后能看到带中文标题和说明的节点。
2. 在 ComfyUI 里把步数改成 30、换一个 SD1.5 模型，按 Ctrl+S 保存；回到应用点检测，确认显示 `Video Generate (edited in ComfyUI) · model <新模型>`。
3. 生成一个“独立”模式的镜头，确认 ComfyUI 历史里的这次任务使用了改过的步数和模型。
4. 删掉正向提示词里的 `{{PROMPT}}` 并保存，确认检测和生成都在付费前报错；点“改用内置工作流”后恢复正常。
