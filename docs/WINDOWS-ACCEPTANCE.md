# Windows 10/11 验收清单

目标为 Windows 10/11 x64。CI 使用 Windows Server 2022，不能据此声称已完成 Windows 11 实机测试。

## 自动化覆盖

- Node 测试：预算、付费请求不自动重试、轮询退避和失败处理。
- FFmpeg + FFprobe：在包含中文和空格的临时路径中，生成不同尺寸的视频并合并。
- Electron 桌面 smoke：真实系统加密往返、加密文件写入中文路径、界面加载、预加载桥接和 Node 隔离。
- NSIS：构建 Windows x64 安装程序，上传 Actions artifact。

## Windows 11 实机验收（尚未执行）

1. 在没有 NVIDIA GPU、Docker、Node.js 的电脑上安装 artifact 中的 exe；确认应用可以启动。
2. 设置 FFmpeg / FFprobe 的完整路径（包括中文和空格），保存设置后重启，确认设置和 Key 状态保留。
3. 保存多个分镜项目，关闭重开，确认项目列表保留。
4. 保持价格为 0，尝试生成，确认拒绝提交。
5. 配置有效价格、低于预估费用的预算，确认预算拦截。
6. 配置有效 Key、区域、模型和图片；在付费确认中取消，确认阿里云无新任务。
7. 仅在明确批准付费后测试生成、轮询、下载和最终 MP4；记录实际账单。
8. 查询任务时模拟网络中断，恢复网络后使用已有任务 ID 继续，确认不重复提交。
9. 备份项目目录后，卸载并重新安装，确认项目保留。

不要把真实 API Key、带私人凭据的 URL 或用户项目提交到 GitHub。

## 0.2 自动短剧流程（尚需真实服务验收）

1. 安装 Ollama 并拉取模型；点击连接检测，确认显示已安装模型；断开服务时应显示错误。
2. 配置可运行的 ComfyUI API 工作流，正向文本使用 {{PROMPT}}，导入；普通 UI JSON 应被拒绝。
3. 点击“生成剧本并编辑”，检查镜头数量、人物描述和旁白，并保存。
4. 用本地 PNG/JPG 图片创建另一项目；删除原始文件，确认项目内副本仍存在。
5. 仅在明确批准费用后测试“一键生成完整短剧”，核对每镜头只有一个 Wan 任务。
6. 在 ComfyUI 已提交后中断应用并重启，检查恢复使用相同 prompt ID；Wan 同理。
7. 确认 MP4 的字幕轨可以开启，SRT 时间轴每镜头 5 秒；启用系统配音后验证语言和声音。
8. 旁白超过 5 秒时应提示修改；编辑旁白后再次导出，不得新增 Wan 视频任务。
9. 从 0.1 升级，打开旧项目并重新导出，确认旧素材与配置保留。
10. 在未安装 ComfyUI 的电脑上用本地图片或 HTTPS 图片仍能生成，说明 ComfyUI 保持可选。

## 0.3 一键环境配置（需 Windows 11 实机验收）

1. 在未安装 Ollama / ComfyUI / FFmpeg 的 Windows x64 电脑上点击“一键下载、安装并连接”；取消确认时不能下载任何工具。
2. 选择 CPU 模式，在无 NVIDIA 的机器验证自动下载、校验、解压、模型拉取、服务启动和工作流配置；至少预留 25 GB 空间，建议 16 GB 内存。
3. 下载中断后重试，检查保留的 .part 文件能够继续；校验失败时不得执行或解压下载内容。
4. 配置完成后检查本地地址为 127.0.0.1:11435 / 18188，点击检测显示两个服务均连接。
5. 关闭并重启应用，点击生成剧本，确认不用手动启动任何本地服务。
6. 填写 Wan 设置并明确批准后验证从故事到 MP4 的全流程；开发自动测试不发起此付费调用。
7. 验证旧设置和工作流已备份，原 API Key、旧项目与素材仍然存在。
8. 独立测试 NVIDIA 模式，使用兼容驱动和足够显存；本模式不是 CPU 用户的前置要求。

CI 对安装器采用小型模拟下载（断点续传、SHA 校验、已有文件复用），不下载数 GB 工具或真实模型。桌面 smoke 使用模拟安装事件验证界面状态变化，不能代替完整首次环境配置验收。
